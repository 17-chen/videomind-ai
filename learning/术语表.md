# VideoMind AI 项目术语表

## 本章学习目标

掌握理解核心调用链所需的中英文术语，并知道它们在项目中的位置。

## 核心术语

### API（Application Programming Interface，应用程序接口）

前后端约定的通信入口。本项目位于 `backend/app/api/v1/`，前端封装位于 `frontend/lib/api.ts`。不要与 UI 页面混淆。

### Route（路由）

把 URL 和 HTTP 方法映射到处理函数，例如 `POST /videos/{id}/process`。路由是入口，service 才承载主要业务用例。

### Dependency Injection（依赖注入）

框架在调用函数时提供所需对象。本项目用 FastAPI `Depends` 提供数据库 Session 和 demo user，见 `backend/app/api/dependencies.py`。

### ORM（Object-Relational Mapping，对象关系映射）

把 Python 类与关系表连接。本项目使用 SQLAlchemy models 表达 Video、Transcript 和 Summary 等关系。

### Pipeline（处理流水线）

按顺序执行的一组步骤。本项目的视频 Pipeline 负责下载、字幕/音频、转写和状态更新，见 `video_processing/pipeline.py`。

### ASR（Automatic Speech Recognition，自动语音识别）

把音频转成文字。它不是 LLM 摘要；本项目默认关闭 ASR，字幕缺失时会因此无法继续完整处理。

### LLM（Large Language Model，大语言模型）

理解与生成文本的模型。本项目默认通过 OpenAI-compatible 客户端调用 DeepSeek，用于视频分析和最终问答。

### Prompt（提示词）

给模型的任务和输出约束。视频分析提示词位于 `backend/app/prompts/analysis_prompt.txt`；RAG 回答还在 `rag.py` 中构造上下文。

### Structured Output（结构化输出）

要求模型返回可被程序验证的数据。本项目请求 JSON object，再用 Pydantic `VideoAnalysisResult` 验证，避免直接信任任意文本。

### Agent Workflow（Agent 工作流）

用状态和节点组织 AI 任务。本项目 LangGraph 图包含 analysis 与 markdown 两个节点；它目前是线性的，不是自主循环 Agent。

### Embedding（向量表示）

把文本映射为数值向量，以比较相似度。本项目使用本地 deterministic hash embedding，而非训练得到的语义模型。

### Vector Store（向量存储）

保存向量并执行近邻搜索。本项目使用 ChromaDB，见 `backend/app/services/vector_store.py`。

### RAG（Retrieval-Augmented Generation，检索增强生成）

先检索项目知识，再把结果给 LLM 回答。本项目的检索、上下文拼装和回答逻辑在 `backend/app/services/rag.py`。

### Idempotency（幂等性）

同一操作重复执行不会产生意外重复结果。embedding 使用固定 `video:{id}` 并 upsert，具备部分幂等特征；整个视频处理流程的重试语义尚未完整实现。

### Background Task（后台任务）

响应返回后在同一应用进程执行的工作。本项目用 FastAPI BackgroundTasks 处理视频；不要与持久化消息队列混淆。

### Migration（数据库迁移）

可版本化地改变数据库 schema。项目已依赖 Alembic，但当前仍使用 `create_all` 和开发补丁，正式 migration 尚未落地。

### CORS（Cross-Origin Resource Sharing，跨源资源共享）

浏览器控制一个来源是否可调用另一个来源的安全机制。前后端分开部署时必须正确设置，见 `backend/app/main.py`。

## 概念关系

- Transcript 是原始文本，Summary 是 AI 理解结果，Markdown Note 是适合阅读的呈现。
- PostgreSQL 保存业务事实，ChromaDB 加速相似度检索，Embedding 负责把文本变成检索坐标。
- LangGraph 组织步骤，DeepSeek 执行模型推理，OpenAI SDK 只是兼容客户端。
- BackgroundTasks 管当前进程内工作；Queue/Worker 管可持久化、可重试的分布式工作。

## 本章小结与下一步

能准确区分“模型、Agent、embedding、向量库与 RAG”，就已经掌握本项目最重要的 AI 工程词汇。下一步可以用《面试问题》检验理解。
