# VideoMind AI 项目面试问题

## 本章学习目标

练习用项目证据说明技术原理、架构边界和工程取舍。

## 基础问题

### 1. 为什么项目同时使用 PostgreSQL 和 ChromaDB？

- **考察点**：关系数据与向量检索的职责。
- **参考回答**：PostgreSQL 保存用户、Video、Transcript、Summary 等业务真相和关系；ChromaDB 保存知识文档的向量并做相似度检索。向量库不能替代业务事务，关系库也不擅长当前实现的语义近邻搜索。
- **参考位置**：`backend/app/models/`、`services/vector_store.py`、`docker-compose.yml`。
- **追问**：Embedding 表为什么只保存 vector ID 映射？

### 2. OpenAI SDK 为什么可以调用 DeepSeek？

- **考察点**：客户端协议与模型提供商的区别。
- **参考回答**：项目创建 `OpenAI` 客户端时传入 DeepSeek API key 和 base URL，复用兼容的 Chat Completions 协议。SDK 是客户端，provider 由配置决定。
- **参考位置**：`services/ai_provider.py`、`core/config.py`。
- **追问**：兼容 API 是否意味着所有 provider 行为完全相同？为什么？

### 3. 什么是 RAG？本项目如何实现？

- **考察点**：检索增强生成链路。
- **参考回答**：先把视频内容 embedding 后写入 Chroma；提问时用相同 embedding 检索当前用户资料；再把结果与问题交给 LLM，最后返回回答和来源。
- **参考位置**：`services/rag.py`、`embeddings.py`、`vector_store.py`。
- **追问**：如果检索结果错误，换更强 LLM 一定能解决吗？

## 项目理解问题

### 4. 一条视频从 URL 到知识卡经历什么？

- **考察点**：端到端调用链。
- **参考回答**：前端创建 Video；用户触发处理；后端下载并优先解析字幕，无字幕时提取音频和 ASR；Transcript 入库；用户触发 AI 分析，LangGraph 生成结构化结果和 Markdown；用户再触发 embedding 写入 Chroma。
- **参考位置**：`video-submit-form.tsx`、`video-actions.tsx`、`routes/videos.py`、`video_processing/pipeline.py`、`video_analysis_agent.py`。
- **追问**：哪些步骤是自动串联，哪些需要用户手动触发？

### 5. 为什么 AI 分析先生成 JSON，再生成 Markdown？

- **考察点**：不确定模型输出的工程约束。
- **参考回答**：JSON 可由 Pydantic 验证并稳定写入数据库；Markdown 是在验证后的结构化数据上确定性生成，减少格式漂移和缺字段风险。
- **参考位置**：`VideoAnalysisResult`、`_analysis_node`、`_markdown_node`。
- **追问**：解析失败时当前如何处理，还可以增加什么重试策略？

### 6. 字幕优先策略有什么价值？

- **考察点**：成本、延迟与降级路径。
- **参考回答**：已有字幕可省去音频提取和 ASR，速度更快、成本更低；缺点是字幕质量依赖来源。当前无字幕且 ASR disabled 时会失败。
- **参考位置**：`video_processing/pipeline.py`、`transcriber.py`、`.env.example`。
- **追问**：如何评估字幕与 ASR 结果质量？

## 工程权衡问题

### 7. 为什么 FastAPI BackgroundTasks 不适合生产长视频任务？

- **考察点**：任务可靠性。
- **参考回答**：它与 API 进程生命周期绑定，没有持久化队列、可靠重试、独立并发控制和跨进程状态恢复。适合 MVP，但长任务应迁移到 worker。
- **参考位置**：`routes/videos.py`；部署审计也记录了该风险。
- **追问**：迁移队列时如何保证同一视频不会重复处理？

### 8. 本地 hash embedding 的优缺点是什么？

- **考察点**：原型速度与检索质量。
- **参考回答**：优点是本地、无 API 成本、确定性强、能跑通向量写入和检索接口；缺点是没有训练语义能力，同义词和复杂中文检索较弱。
- **参考位置**：`services/embeddings.py`。
- **追问**：替换为 bge-m3 前应如何建立离线评测？

### 9. 为什么不能把当前 Docker Compose 直接称为生产就绪？

- **考察点**：开发与生产环境差异。
- **参考回答**：Dockerfile 使用 dev/reload，缺少正式 migration、持久任务队列、认证、生产存储与确定的 Chroma 部署策略；也没有 CI/CD 配置。
- **参考位置**：两个 Dockerfile、`database/session.py`、`docs/deployment-audit.md`。
- **追问**：若目标是最快作品集上线，你会先牺牲哪些能力？

### 10. 你能否证明项目真的按 Phase 1–6 逐步开发？

- **考察点**：证据意识。
- **参考回答**：不能完全证明。README 和 PROJECT_CONTEXT 声明六阶段完成，但初始实现被压缩在一个大提交中；Git 只能确认最终文件集合和后续两次演进。
- **参考位置**：提交 `f97010a` 一次加入约 100 个文件，因此无法恢复更细的历史顺序。
- **追问**：以后如何让开发历史更适合复盘和教学？
