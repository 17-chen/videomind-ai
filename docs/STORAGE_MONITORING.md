# 本地磁盘只读对账

2026-10-30：R8 运营检查子项。命令仅查询数据库归属、文件元数据和磁盘容量；不会打开业务文件正文、删除文件或修改数据库。

```bash
docker compose exec -T backend python -m scripts.storage_status
```

输出 JSON，不包含目录路径、文件名、视频/用户 ID、邮箱、链接或异常原文。命令读取配置中的 video/audio/transcript/note 四类目录，汇总以下项目：

| 字段前缀 | 含义 |
| --- | --- |
| `owned_*` | 文件名前缀对应当前数据库视频 ID 的普通文件 |
| `orphan_id_*` | UUID 前缀符合生成命名规则，但查询时没有对应视频记录的普通文件；只是疑似孤立文件 |
| `pending_upload_*` | 没有视频记录且以 UUID 命名的 `.part` 文件；可能是尚未提交的上传 |
| `unmanaged_*` | 不符合上述归属规则的普通文件；不能据此断定可删 |
| `staging_*` | `.staging-*` 目录及其内部普通文件的数量与字节数；可能仍在使用 |
| `symlinks` | 扫描时识别出的符号链接数量，跳过目标 |
| `unmanaged_directories` | 普通未知目录数量，不递归扫描其内容 |
| `scan_errors` | 无法读取或扫描期间消失的项目数，不输出异常路径 |
| `disk_total_bytes` / `disk_free_bytes` | 根目录所在文件系统的总量/剩余容量；同一磁盘上的多个根会重复报告，不能相加 |

符号链接根目录不会遍历，标记为不完整。完全相同的配置根目录只扫描一次，其余使用 `duplicate_of` 引用。普通文件按逻辑字节数统计，不等于实际物理磁盘占用；符号链接不纳入普通文件字节统计，与用户配额中链接自身大小的核算存在这项差异。

## 状态和限制

- `status=complete`：本次选定范围内扫描没有发生错误，不表示磁盘没有问题，也不表示可以删除任何文件。配置根不存在时 `exists=false`，磁盘字段为空；需要结合部署配置判断。
- `status=incomplete` 或数据库/命令异常：退出码 2，避免把权限不足或扫描中断伪装成健康空盘。成功扫描退出码 0，即使发现疑似孤立文件。
- `consistency=best_effort`：数据库与文件系统不是原子快照。即使 `active_tasks=0`，仍可能有同步上传或编辑在途；不能把快照作为自动清理依据。
- `cleanup_performed=false` 恒定。当前工具没有删除参数，年龄或没有数据库记录都不是充分的删除条件。后续清理必须考虑上传提交、Worker 租约、文件归属和可恢复流程。
- 只递归扫描识别为暂存的目录，跳过扫描时识别出的符号链接；没有为并发恶意路径替换提供原子安全保证，因此不能直接扩展为清理器。
- 模型缓存、数据库、Chroma、备份和其他目录未展开统计，仍需要独立的主机容量监控、阈值告警和生产日志汇聚。
