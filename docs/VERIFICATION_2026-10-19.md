# 2026-10-19 本地上传核查

## 范围

本轮实现 R3 本地视频上传代码：工作台入口、上传限制接口、文件流式保存、扩展名/MIME/ffprobe 实际视频流校验、同一用户哈希防重复、归属查询、处理流程和删除清理。视频文件由服务端生成的 UUID 命名；源链接使用内部标记，向量引用使用应用内详情页。

## 实际验证

- 开工前 `main` 工作树干净、与 `origin/main` 一致。本机后端和 PostgreSQL 容器正常，无活跃视频任务。
- 后端完整 `python -m pytest -q`：**66 passed，1 条 LangGraph 待弃用警告**；`ruff check app tests scripts` 通过。上传测试包含越权读取/删除、跨用户同内容、本人重复、超限、无效媒体和模拟转写→笔记→索引工作流。
- 前端临时副本 `npm run build`、`npm run typecheck`、`npm run lint` 通过，未覆盖预览服务的 `.next`。
- 使用 ffmpeg 自生成 1 秒黑色视频，实际 ffprobe 返回视频时长 1 秒；伪装为 MP4 的文本文件被拒绝为 415。
- 本地 PostgreSQL 从 `20261008_0004` 迁移到 `20261019_0005 (head)`；迁移前备份保存在被 Git 忽略的 `storage/backups/`，权限为仅当前用户。没有重置数据卷。
- 运行中 VideoMind API（宿主 8001、容器 8000）经重启加载新路由后，自生成视频上传 **201**、重复上传 **409**、详情读取 **200**、删除 **204**，生成文件已清理。前端开发进程重启后，工作台页面实际包含文件输入和上传入口。

## 未验收边界

- R3 的真实上传→ASR→AI 笔记→入库仍未完成：当前演示环境没有启用真实本地 ASR，也没有本人服务商 Key；模拟全链路只证明代码路径。
- 真实 Supabase 双用户隔离和真实服务商计费未验收；测试中身份与模型调用均为模拟。
- R1 独立镜像尝试安装可选模型依赖时，构建停在 Debian apt 下载阶段且几分钟未继续输出，已人工取消。没有模型版本、真实音频或 BGE 对照结果；运行中的服务和模型配置未改变。
- 上传限制在应用层按流式读取检查；生产入口还需要代理层请求体限制、总存储配额和持久对象存储，属于 R8/R6。
