不在文档或 Git 中保存任何真实密钥。上述账号注册、授权和等待时间不计入 50–80 小时；账号配置后的测试和修复已经计入。

## 推荐开发顺序

1. 真实本地模型和视频烟测，使用本轮固定评测找出质量问题。
2. 上传和资料编辑，收束本地完整操作。
3. 持久化队列、取消和状态恢复。
4. 存储适配、部署配置与账号就绪后的端到端验收。
5. 密钥轮换、配额、监控、恢复和上线检查收尾。
