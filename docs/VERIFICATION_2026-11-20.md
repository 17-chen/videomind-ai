# 2026-11-20 问答错误路径核查

## 实现

`POST /chat` 先去问题首尾空白，再执行1–1000字符校验。纯空白（含换行、制表及全角空格）返回422，路由不执行，不发生检索、模型调用或RequestWindow计数。正常问题以去空白后的正文进入检索及提示词。

问答请求按OpenAI兼容SDK的异常类型转换固定中英文ApiError：认证/权限502，额度/频率503，超时504，连接503，其他SDK异常502。模型响应无choices、正文为None/空/全空白时502，不再返回200并附带错误文本/来源。服务商错误正文、请求地址和凭证不回传。本站鉴权401、应用限流429和个人Key缺失400保留原语义；不改变SDK默认重试策略。

前端已有错误提示与显式重试交互，无需改前端源码。没有更换依赖或数据结构；本人Key解析、归属过滤、来源编号行为保持原实现。
