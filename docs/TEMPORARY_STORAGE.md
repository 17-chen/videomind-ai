# 临时处理空间保护

2026-11-12 更新：R8 子项，补充正式用户文件配额之外的生成阶段保护。现有 Next.js/FastAPI/SQLAlchemy 架构和用户密钥归属规则不变。

## 配置与反馈

| 配置 | 默认 | 作用 |
| --- | --- | --- |
| `MAX_MEDIA_STAGE_MB` | 2048 | 每阶段暂存目录的容量预算；音频单输出文件同时使用此值作为内核文件大小上限 |
| `MIN_MEDIA_FREE_SPACE_MB` | 1024 | 在指定检查点要求所在文件系统保持的剩余空间；0 关闭该余量阈值 |
| `VIDEO_DOWNLOAD_TIMEOUT_SECONDS` | 1800 | 下载进度/后处理检查点的耗时预算，沿用既有配置字段 |
| `AUDIO_EXTRACTION_TIMEOUT_SECONDS` | 900 | 音频提取子进程超时，沿用既有行为 |

MB 按 1024 × 1024 字节。上传有效上限为 `min(MAX_UPLOAD_MB, MAX_MEDIA_STAGE_MB)`，策略接口与前端保持一致。大小超限返回 413；已知剩余空间不足返回 507；后台任务保留明确失败原因。等大/缩小替换仍要满足暂存空间条件，删除视频不受这项生成前置检查影响。

## 各阶段实际约束

- **阶段入口与发布前：**创建私有 `.staging-*` 之前检查剩余空间，生成结束后核算全部输出，再执行已有用户文件总量和发布规则。超限不替换旧文件，正常异常会清理本次私有暂存目录。分片在扫描期间被下载器删除/改名时跳过消失项，后续检查继续核算现存文件。
- **上传：**每次写入应用管理的 `.part` 之前检查累计字节与剩余空间。失败清理本次部分文件并回滚，不删其他文件。FastAPI 在进入服务函数前的 multipart 接收/系统临时文件不由此处限制。
- **下载：**向 yt-dlp 设置单文件 `max_filesize`，在下载进度、后处理检查点检查暂存文件总量、磁盘剩余空间和耗时。内置 Content-Length 拒绝有时早于进度钩子或 filesize 元数据，额外识别其拒绝事件，统一呈现容量错误，避免误报“找不到输出文件”。原始下载日志不直接输出到控制台。
- **音频：**在全新 Python 子进程中禁用 core dump、设置 POSIX `RLIMIT_FSIZE` 后 `exec` ffmpeg。避免改变有心跳线程的 Worker 本身限制，也不使用线程环境中的 `preexec_fn`。不采用会静默截断的 `ffmpeg -fs`；输出触及限制即失败，不能将截断音频作为成功结果发布。ffmpeg 运行中父进程约每0.5秒检查暂存文件系统余量，低空间或探测失败时终止并回收直接子进程后才清理本次暂存；标准输入/输出/错误流使用 DEVNULL，不累积工具原始日志。
- **文本：**字幕、ASR 转写和 Markdown 写文件前按 UTF-8 字节数检查大小与所需空间。自动笔记还在模型调用前做已知低空间预检；若已保留手工笔记而不生成新文件，不执行这项笔记文件预检。

Linux 下 launcher 还设置 `PR_SET_PDEATHSIG=SIGKILL`，随后核对预期父 PID：Worker 在设置前退出或设置失败时不启动命令；设置后退出则内核停止当前音频进程。绑定针对创建子进程的 Worker 执行线程；当前 Worker 在主线程执行音频，心跳线程独立。Compose Worker 启用 `init: true` 回收被收养子进程。依赖普通、无提权的 ffmpeg exec；不承诺其他后代进程或非 Linux 的父进程退出保护。

音频执行器要求 POSIX resource 支持；当前 Docker/Linux 与 CI 为支持范围。没有在不支持的原生系统上回退到无限制执行。

## 尚未解决的边界

1. **整块磁盘没有全局硬上限或统一预留。**下载进度与后处理检查是协作式的，可能先写入一个数据块才报告；yt-dlp 的合并子进程、字幕下载或阻塞网络阶段可能在下一个检查点之前占用更多空间。多个用户/Worker 也可能同时通过余量检查。
2. 音频单文件是内核限制，但音频提取过程中的磁盘余量已增加约每0.5秒的采样检查；它不等于全主机磁盘配额。其他缓存、数据库、备份、向量库和系统临时目录也未纳入。
3. 下载耗时预算在检查点检查，不能保证在配置秒数到达时立刻终止所有网络/后处理调用。音频超时能终止并回收当前执行进程；2026-11-01 真实 ffmpeg 已验证随 Linux Worker SIGKILL/SIGTERM 停止及租约重试。强制退出遗留暂存目录保留；下载合并子进程、付费步骤和长期多实例仍需 R5 演练。
4. 字节上限针对落盘文件，不限制模型响应/转写解析的内存峰值。模型调用后才知道实际输出大小，仍可能发生已计费但最终保存失败；已知低空间预检不保证调用期间空间不变化。
5. 没有自动清理既有孤立文件、未知目录或 SIGKILL 遗留文件；年龄/扫描结果不是删除授权。继续使用只读对账和恢复手册核对。

因此只完成“检查点容量保护 + 音频单文件限制”子项，不能勾选 R8 全部磁盘耗尽防护。
