# VideoMind AI 分阶段任务路线图

> 更新日期：2026-08-26
> 原则：先保证本地闭环稳定，再上线作品集版本，最后演进为多用户 SaaS。

## 当前定位

- Phase 1-6 已完成基础产品闭环和中文 UI。
- 当前进入 Phase 7：本地生产化基础。
- 当前可以用于本地演示，但还不能视为正式多用户生产系统。

- [x] 建立 Alembic 配置和首次数据库迁移。
- [x] 区分开发 Compose 命令与生产 Docker 启动命令。
- [x] 增加 API 存活检查和数据库就绪检查。
- [x] 细化视频处理状态：下载、转写、分析、向量写入、完成和失败。
- [x] 在全新 PostgreSQL 数据库执行 `alembic upgrade head`。
- [x] 验证 Docker 前后端生产镜像构建。
- [x] 升级 Next.js 16.3.3 并清除前端生产依赖安全告警。
- [ ] 本地跑通一次完整视频闭环。

验收：全新数据库可迁移；前后端生产构建通过；健康检查准确；核心视频流程无回归。

## Phase 8：本地完整能力

目标：无字幕视频也能处理，并提升中文检索质量。

- [ ] 接入 `faster-whisper` Provider，保持 ASR 接口可替换。
- [ ] 用真实中文 Embedding 模型替换 deterministic hash embedding。
- [ ] 增加处理耗时、Provider、模型和失败阶段日志。
- [ ] 补视频 Pipeline、AI 分析和 RAG 的服务层测试。
- [ ] 增加失败重试和任务取消能力。

验收：有字幕和无字幕样例都能生成笔记；中文语义检索结果可解释；失败可定位并重试。

## Phase 9：作品集上线

目标：获得无需域名也能公开访问的前后端地址。

- [ ] Vercel 部署 `frontend`。
- [ ] Render 部署 FastAPI Docker 服务。
- [ ] Supabase PostgreSQL 执行 Alembic migration。
- [ ] 使用 Supabase Storage 保存上传视频、音频和笔记文件。
- [ ] 配置生产 CORS、API URL、DeepSeek Key 和随机 Secret。
- [ ] 将向量层迁移到 Supabase pgvector，减少 Chroma 运维服务。
- [ ] 建立线上冒烟测试和故障排查文档。

验收：公开网址可提交视频、查看结果、搜索知识库和对话；重新部署不会丢失数据库和文件。

## Phase 10：多用户 SaaS

目标：从作品集 Demo 演进为可持续运行的用户产品。

- [ ] 接入正式注册、登录和会话管理。
- [ ] 所有查询执行用户级权限隔离。
- [ ] 引入 Redis + Celery Worker 执行长视频任务。
- [ ] 增加任务进度、重试、幂等和并发限制。
- [ ] 加入配额、审计日志、监控、告警和成本统计。
- [ ] 增加隐私政策、数据删除和视频来源合规说明。

验收：多个用户的数据严格隔离；任务重启可恢复；关键失败可监控；资源成本可控制。

## 当前已知问题

- Demo User 不是正式认证系统。
- FastAPI BackgroundTasks 不适合可靠执行长视频任务。
- 本地文件目录在多数云平台上是临时文件系统。
- ChromaDB 尚无生产持久化方案，计划在线上阶段迁移 pgvector。
- ASR 默认关闭，无字幕视频暂时不能完成转录。
- Hash Embedding 只适合验证流程，不代表生产语义搜索质量。
- yt-dlp 对平台策略、Cookie 和云服务器网络环境敏感。
- 当前自动测试覆盖范围较小，缺少端到端测试和 CI。
