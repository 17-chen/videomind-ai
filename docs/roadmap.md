## 2026-10-08 一键流程进展

视频详情新增“一键处理并入库”，串联字幕、AI 笔记和向量写入；失败后可从已保存的转写或笔记继续。后台权限与重复请求已测试，真实 URL 和付费模型调用仍待验收。运行方式为 FastAPI BackgroundTasks，服务重启后的任务恢复仍是后续工作。
