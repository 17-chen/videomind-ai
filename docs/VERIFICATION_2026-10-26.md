## 改动与边界

- 视频处理、完整运行、分析及入库四类 API 入队时记录 `request_id`、服务端任务 ID 和类型。HTTP 响应的 `X-Request-ID` 可关联这条记录，再用任务 ID 查询 Worker 的领取、阶段开始、恢复和终态日志。日志事件仅写服务端生成的 ID 与固定状态字段；异常只写类型。
