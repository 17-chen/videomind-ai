# 可选的跨进程临时空间预留

2026-11-26：R8新增协作式准入。原有 [阶段大小/余量检查](TEMPORARY_STORAGE.md)、下载进程组监督和音频单文件限制继续生效。本机制协调接入它的进程，不能替代文件系统硬配额或生产网关。

## 启用条件

`MEDIA_RESERVATION_DIR` 默认空，沿用原检查点行为，不创建登记目录或文件。启用时，操作者先在媒体输出所在的**同一块本地POSIX文件系统**上创建专用登记目录，权限0700，归属API/Worker共同的有效Unix UID；父目录必须可信，路径及祖先不能含符号链接或`..`。推荐用四个业务目录的同盘兄弟目录，例如 `/app/storage/reservations`。工具不自动创建登记目录，也不修改真实环境。

所有共享同一磁盘的API、Worker必须指向同一个实际登记目录，并安装相同实现；不能用独立目录分别计数。不支持不保证flock语义的网络文件系统、不同UID混用或主动更换/修改活动登记目录。跨独立主机/独立磁盘分别管理当地磁盘，不把这个目录当作分布式云存储配额。启用前须在目标部署挂载上验证锁语义；本轮只验Linux临时文件系统，没有验收真实部署挂载。

```text
MEDIA_RESERVATION_DIR=/app/storage/reservations
MAX_MEDIA_STAGE_MB=2048
MIN_MEDIA_FREE_SPACE_MB=1024
```

这是配置示例，不是已启用的环境。新变量已加入 `.env.example`，现有预览保持关闭。启用后，登记不可读、权限/格式/文件系统不符、锁不可用或忙超时均返回已有固定文件存储503，不回退无预留模式；预算不足返回已有临时空间507。消息沿用既有中英文映射。

## 如何计数

- 每次准入在短暂全局flock下读取实际磁盘余量及活动预算。只有 `free_bytes - active_reserved_bytes - requested_bytes >= MIN_MEDIA_FREE_SPACE_MB * 1024²` 才登记新预算。锁等待最多约2秒，不持有长SQL锁或在模型/媒体执行期间占用全局锁。
- 下载、音频、字幕/转写、自动/手工笔记等生成暂存目录预留完整 `MAX_MEDIA_STAGE_MB`。未知输出不按预期小文件量提前承诺空间；自动笔记模型调用移入暂存生产函数，在预留后才调用。保留手工笔记的再分析不生成文件，因此不要求新文件预算。
- 本地上传预留 `min(MAX_UPLOAD_MB, MAX_MEDIA_STAGE_MB)`；云端上传通过生成暂存预留阶段预算。此准入发生在服务函数读取UploadFile之前，但不覆盖FastAPI接收multipart时已经产生的系统临时文件。
- 对象单文件/成组落地缓存按账本声明的精确大小/总大小预留，预算保持到整个缓存使用及清理结束。缓存与正在生成的输出同时占盘时会同时计数。
- 当前free已反映部分实际落盘字节，活动预算仍完整保留，不在过程中返还已写字节。因此计算有意保守，可能拒绝实际上还能写下的小任务。若整个阶段上限无法预留，即使输出预计很小也会拒绝；应按真实磁盘/工作负载配置上限，不能为了绕过拒绝强改登记文件。

所有MB均按1024²字节；登记记录不预分配实际文件块，也不统计文件系统元数据/分配开销。正常异常路径先停止受监督进程、清理本次暂存/缓存，再关闭预留。已发布文件的物理占用仍由实际free体现，用户正式文件/对象配额保持独立。

## 进程退出和登记文件

每条记录仅包含版本、设备号和预算字节；文件名为独立随机标识，不包含视频/用户ID、URL、密钥或业务路径。最多4096条活动记录，读取单条最多128字节；登记扫描遇未知文件、格式异常、符号链接、FIFO、目录、非私有权限或硬链接均失败，保留该条数据，不猜测可清理。

活动状态由记录文件的排他flock决定，不依赖PID、创建时间或“超时即失效”。进程退出后内核关闭其描述符；下一次准入只移除本实现格式合法且无锁的登记元数据，不删除媒体或清理遗留暂存。磁盘实际free继续反映遗留文件。意外退出或主机掉电留下损坏登记文件时会拒绝，须在停止所有参与者后核查，不通过忽略记录释放预算。

下载运行器和音频launcher显式继承当前预留描述符；父进程退出或关闭上下文时，只要受监督子进程仍持有描述符，记录仍计入预算。正常关闭若发现子进程仍持锁，则保留登记，直到子进程退出后由后续准入回收。文件清理失败只留下无锁元数据并记录固定提示，不把已经提交的上传伪装为失败。

## 未覆盖的边界

该机制是协作式准入，不是全磁盘写入硬上限。进程仍可能在采样间隔超写，未接入本机制的程序、数据库、向量缓存、系统临时目录、备份和直接调用基础下载器都可以消耗磁盘。原有采样及音频内核上限仍负责运行期间的检查。主动脱离监督/关闭继承描述符的后代不受预留协议保证。

登记目录是受信任的内部状态，不抵御同一UID的恶意进程或管理员篡改。磁盘空间、挂载或权限可以在准入后变化；目录文件系统被替换及不可中断的I/O也不具硬实时保证。模型输出大小仅在返回后可知，已知预留成功不保证模型响应可最终保存或不发生服务商计费。

未提供按年龄自动清理业务文件、云端总空间预留或长期多实例负载验收。本轮仅使用合成数据、真实Linux锁/子进程和本地合成HTTP媒体；详见 [核查](VERIFICATION_2026-11-26.md)。
